# ぶつかり勇者（BUMP HERO）

指でグリグリ動かして体当たりで戦う、ドット絵のダンジョンRPG。絵も音もすべてコードで生成している。

## APK
`main` に push すると GitHub Actions が APK をビルドし、Releases の **latest** に `ButsukariYusha.apk` を置く。
スマホで Releases ページを開いてダウンロード → インストール（提供元不明のアプリの許可が必要）。
署名は固定のデバッグ鍵（`app/debug.keystore`）なので、新しいビルドを上書きインストールできる。

## 構成
```
web/                 ゲーム本体（このフォルダだけでブラウザでも動く）
  index.html         画面（ページ本文。claude.ai のアーティファクトと同じ形）
  yusha.js           ゲーム本体（ダンジョン・操作・戦闘・ボス・街・ショップ）
  sprites.js         ドット絵（勇者・敵・ボス・タイル・置物・エフェクト）
  fantasy.js         音のエンジン（BGM・効果音・ジングル）
  arrangements.js    BGMのアレンジと音量バランス
app/                 Android（WebView でゲームを表示）。ビルド時に web/ を assets にコピー
tools/wrap.sh        web/_test.html を作る（PCのブラウザで試す用）
```
Android の戻るボタン：ウィンドウを閉じる → ダンジョンならポーズ → 街なら門のページへ → 門のページで押すとアプリを閉じる。
アプリを切り替えると、音楽とゲームは止まる。


## 遊び方
- 画面のどこでも指を置くとそこがスライドパッドになる（倒した方向・量で移動。指が外に出るとパッドがついてくる）
- パッドを**大きく倒すと突進**（点線の輪より外）。パッドは大きめで、輪の内側では細かく歩ける。オレンジに光っていれば体当たりが攻撃になり、当たると反動で跳ね返る。速いほどダメージが大きく、全開なら時々「かいしん」
- ゆっくり触れると敵の攻撃を受ける。弾・剣・火・衝撃波にも注意
- **ころがり回避**：指をすばやくはじく（フリック：0.24秒以内に30px以上）と、その方向へ転がる。転がっている0.3秒は攻撃を受けず（眠り・石化・つかみも無効）、敵や弾をすり抜ける。攻撃にはならない。次に転がれるまで0.7秒
- 敵を倒すと経験値とゴールド。レベルアップで HP・こうげき・ぼうぎょ が上がる
- 宝箱・木箱は体当たりで開く。ボス部屋の手前に「いやしの泉」（HP全回復）
- **ボスの扉は封印されている**：通路の魔物を半分以上倒すと開く（右上の深さメーターの下に「とびら 12/24」と出て、開くと「とびら OK」）。封印中は扉に鎖と錠前が付き、近づいてもはね返される。扉の前で待っていると、取りこぼした遠くの魔物が数体ずつ呼び寄せられる
- 右下ボタンで、持ってきたどうぐを使う（ダンジョンに入る前の「じゅんび」で選んだもの）

## 街
1画面に1つの建物。左右にスワイプ（または ◀ ▶）で切り替え、建物をタップすると中に入る。端まで行くと反対側につながる（ループ）。切り替えは無音、建物に入るときの音とメニューのボタン音は控えめ。
- **勇者の家**：つよさ・せってい・あそびかた
  - せってい：BGM・効果音の音量、画面のなめらかさ（じどう＝画面に合わせる／30／60／90／120fps）、スライドパッドの濃さ（うすい／ややうすい／ふつう／こい、見本つき）
- **ダンジョンの門**（最初に表示）：ダンジョンを選んで出発。リストは前回出発したダンジョン（はじめは最新のダンジョン）が真ん中に来た状態で開き、その行が光る
- **どうぐや**：回復・強化アイテム（家に各99こまで置ける。×10でまとめ買い）、スキルのしょ
- **かじや**：ぶき・よろい・くつ・そうしょく

アプリを閉じたり別のアプリに切り替えたりすると、ゲーム（音楽・処理）はすべて止まり、ダンジョン中ならポーズになる。

街に戻るとHPは全回復（宿屋は廃止）。やられると、その探索で拾ったゴールドの半分を失う（レベル・経験値はそのまま。ポーズから自分で街へ帰った場合は失わない）。セーブはブラウザに自動保存。

### 難易度の目安
- 1〜5ステージ：初見でそのまま進めばクリアできる強さ（1回のクリアで次の推奨Lvに届く経験値）
- 6ステージ以降：最新のステージを3回ほど回ってレベル上げ・お金かせぎをすると、次のステージに挑める強さ
- 1回の探索で手に入るゴールドはステージごとに約1.2〜1.45倍。3回分で次のランクの装備が買える目安
- 16ステージ以降も同じ考え方（ボットで試すと、1ステージあたり周回1〜3回＋挑戦の失敗1〜2回）。まおうは最後らしく少し手ごわい
- 15ステージ版のセーブデータはそのまま引き継げる（魔王城をクリア済みなら25番目にクリア印が付き、15番目から挑める）
- 26〜30も同じ考え方。モンスターはかたくなるが攻撃力の伸びはゆるめ。はかいしんはいちばん手ごわい
- **眠り・石化**：勇者が少しのあいだ動けなくなる状態（Zzz／灰色）。解けたあと数秒は同じ状態にならない

## キャラクターの見た目
勇者・ザコ敵73種（うち色違い20種、ゴールデンスライムを含む）・ボス35体は、すべてドット絵の2.5頭身チビキャラ（`sprites.js`）。
- 絵はコードで描いている。小さなキャンバスに四角や多角形で描き、くっきりしたドットに整え、1ドットの黒い縁取りを付けて、ポーズごとにキャッシュする。1ドット＝1.5ピクセルで、全キャラ同じ密度。
- 勇者：
  - 上下左右の4方向と歩きの動きがある。
  - 突進中は剣を突き出し、残像が出る。
  - やられたときの顔、まばたき、マントのはためきもある。
  - 武器23種・防具22種の組み合わせで見た目が変わる（剣の色・長さ・光、よろい・かぶと・盾・マントの色）。31〜35の装備は形も変わる（曲刀・さんご・稲妻・のこぎり刃・星の剣先、肩当て・ヒレ飾り・火花・角・翼）。
  - 31〜35のそうしょくは、つけると小さなドット絵になって勇者のまわりをふわふわ回る（街でも見える）。
- ザコ敵：構え・攻撃・突進・詠唱などの状態ごとにポーズが変わる。勇者のいる側を向く。
- ボス：
  - 待機と攻撃のポーズがある。HPが半分を切ると、目の色が変わり、赤いオーラが出る。
  - ヴォイドアイは勇者を目で追う。
  - キングスライムはジャンプ中に縦に伸びる。
- 当たり判定はこれまでどおり丸のまま。キャラの足元を丸の下側にそろえてある。

- 攻撃予告の範囲は網点（ディザ）表示。
- 体当たりの火花（かいしんは大きい）と、敵を倒したときの煙はドットのアニメーション。
- 武器を持つ人型キャラは、肩→ひじ→手の腕を振って武器を振る（サイクロプス、ゴブリン、ガイコツ剣士、やみの騎士、サハギン、ゴブリンキング、デスナイト、ゆうれいせんちょう）。ふりかぶり→振りおろし→戻りの順に動き、ボスの「おおぶり」では武器そのものが攻撃範囲まで伸びる。ボスは下半身も連動し、ふりかぶりでのけぞって片足を上げ、振りおろしで踏み込んで腰を深く落とす（ひざが曲がる脚・腰のひねり・マント／幽霊の尾のなびき）。雑魚も体重移動と踏み込みが付く。デスナイトは正面・左右・後ろの3方向の絵を持ち、勇者のいる方を向く。体は簡単な3D骨格（腰・ひざ・肩・ひじ）で動かして向きごとに投影するので、ひざは前に曲がり、構えは前後の踏み込みになる。「おおぶり」では剣と一緒に体が回る。人型でないボスのうち、ナイトメア・フェンリル・ボーンドラゴン・リヴァイアサン・ケツァルコアトルも正面・左右・後ろの3方向で動く（web/beasts3.js。骨格を3Dで動かし、毎フレーム小さなドット絵キャンバスに描いて輪郭を付ける）。ナイトメアは前脚を振り上げて棹立ちになり駆ける、フェンリルは座って遠吠え・ブレスで首を振る・身をかがめて跳ぶ、ボーンドラゴンは翼を打って踏み鳴らし尾を振り回す、リヴァイアサンは水から首とうねる胴を出してのけぞる、ケツァルコアトルは虹色の翼で羽ばたき体をくねらせる。回転攻撃はダメージバーではなく体そのもので行う（リヴァイアサンは海面から触手が4本立ち上がって叩きつけ振り回す、ボーンドラゴンは骨の尾、ケツァルコアトルは胴の後ろ半分を振り回す。描く長さ＝当たり判定の長さ）。正面から見た口は、下あごが下がって牙と口の中が見える。ヒュドラ（首ごとに揺れ、3方向ブレス・時間差の噛みつき・首がうなだれて再生、首振り攻撃は首そのものが伸びて薙ぐ）、ケルベロス（3つの頭・炎のたてがみ・蛇の尾、前脚を上げて踏み鳴らす、尾の攻撃は蛇の尾が振り回す）、ヴォイドアイ（虹彩が本当に球の上を動いて相手を見る、ビームで瞳が細まり触手がこわばる）、クロックマシン（横から見ると時計の厚み、後ろは歯車とゼンマイ、時計の針の攻撃は文字盤から巨大な針が伸び床の影が当たり判定）、クラーケン（8本の腕、腕の攻撃は4本が立ち上がって叩きつけ振り回す）も3方向で動く。触手・首・尾で回転攻撃をするときは、体ごと回る（始まる前に逆向きに少しひねってためる）。カメラは1つの斜め見下ろしで、体の3D骨格を向いている角度のまま回すので、向きが変わってもなめらか（顔の絵だけが正面・横・後ろで切り替わる）。普段も勇者の方へ少しずつ向き直る。クラーケンの腕は体の外側から伸びる。キングスライム（ジャンプ前にしゃがみ、空中で伸び、着地でつぶれる。顔と王冠が体と一緒に回る）、ジャイアントトレント（樹皮の顔、枝の腕、根で踏み鳴らす）、クイーンスパイダー（8本脚が交互に動く、前脚を上げる、ビームで目が光る、腹を上げて糸を放つ）、えんりゅう（翼・首・炎の尾。尾の回転攻撃は体ごと回る）、サンダーバード（羽ばたき続け、翼に稲妻、急降下で翼をたたむ）も3方向で動く。ブレス・火の玉・光弾・ビームは、描いたボスの口（ヴォイドアイは瞳）から出る。首が複数あるボスは、それぞれの口から吐く。ブレスの予告線も口から出る。
- 街もドット絵：
  - 帯状の夕焼け空と月、山並みと魔王城のシルエット
  - 芝生と石畳の道
  - 壁の板・れんが、うろこ屋根の質感、光る窓、扉
  - 店の中：棚の薬びんや剣と盾、店主（どうぐやの娘・かじやの親方）
- 低解像度で描くぶん処理も軽くなった（手元の計測で1フレームが約8分の1）。
- ドット絵レイヤーはそのまま画面に置き、ブラウザ（GPU）にくっきり拡大させている。毎フレームの大きな拡大コピーがなくなり、描画の処理時間はさらに約3分の1（見た目は同じ）。文字とHUDは上の透明な層に高解像度で描く。

## 画面の形
- どの縦長スマホでも、横幅は同じ（360）で、縦に長い画面ほどダンジョンが先まで見える。
- 横に広い画面（タブレット、折りたたみの内側、横向き）も全画面で表示する。キャラの大きさは変えず（拡大率は高さで決めて上限あり）、広いぶんは通路のまわりの壁・ボス部屋・街の景色が左右に広く見える。通路やボス部屋の大きさ（遊ぶ範囲）はどの画面でも同じ。
- パンチホール・ノッチと下のジェスチャーバー（safe-area）を避けて、HUD・スキルボタン・ウィンドウを置く。APK はそのぶんを画面の上下に空けず、背景は全面に描く。
- 画面の回転・折りたたみ・分割表示で大きさが変わると、その場で合わせ直す。

## 効果音
DOPAMINE TUNNEL の効果音とボイスをやめ、ファンタジー風の効果音を `fantasy.js` で合成している（28種）。
- **戦い**：体当たり（ドスッ）、かいしん（斬撃とキラキラ）、ボスへの一撃、盾ではじかれる（カキン）、被弾、敵をたおす（ボフッとキラキラ）、地響き、爆発、魔法弾、怪しい弾、召喚、ワープ、ボスの咆哮
- **探索**：コイン（連続で拾うと音程が上がる）、宝箱（きしみとジャーン）、木箱をこわす、アイテムを拾う、回復（ハープ）、いやしの泉、ちからのくすり・まもりのくすり、レベルアップのファンファーレ、ボス部屋の扉、ボス登場（どら＋金管）、やられた
- **街**：決定・選択（ハープ）、出発、買い物（コインとベル）、装備（剣を抜く音）
- BGMと効果音は同じ出力（音量設定・圧縮）を通る。効果音は小さな部屋の響きをまとっている。

## 音楽
DOPAMINE TUNNEL のダンス曲エンジンをやめ、王道ファンタジーのオーケストラ風BGMを新しく作った（`fantasy.js`。サンプル音源は使わず、すべてWeb Audioで合成）。

- **3つのテーマ曲**（オリジナル）
  - 冒険のマーチ：ダンジョンの曲（勇ましい4拍子、前奏＋A・A'・Bの32小節）
  - たたかいのテーマ：ボス戦の曲（疾走する短調、前奏＋A・B・A・Cの28小節）
  - 村のワルツ：街の曲（のどかな3拍子、32小節）
- メロディは「音階の何番目か」で書いてあるので、同じ曲を長調・短調・フリギア（スペイン風）・二重和声的音階（中東風）などに置きかえられる。
- **アレンジ**（`arrangements.js`）：調・旋法・テンポ・楽器・伴奏・ベース・打楽器・残響・環境音をダンジョンごと、ボスごとに変えている。例：
  - まよいの森：自然的短音階、フルートのこだま、フクロウ
  - 溶岩洞：フラメンコ風（ギター、カスタネット、手拍子）
  - こおりの塔：オルゴールと鈴
  - ピラミッド：ウードとダルブッカ
  - 時計塔：チェンバロとチクタク
  - 魔王城：パイプオルガンと合唱
- ボスはHPが半分を切ると、テンポが上がり、トレモロと金管が加わる（まおうは半音上に転調）。
- 街は建物を切り替えると、次の小節から楽器が変わる。門はフルートと弦、勇者の家はオルゴール、どうぐやはクラリネットとピチカート、かじやはホルンと金床。
- ダンジョン制覇のファンファーレと、やられたときの短い曲もある。
- 勇者の家の「おんがくしつ」で、たどりついたダンジョンとたおしたボスの曲（いかり版も）をきける。
- 楽器ごとの音量と各曲のパートバランス（メロディ／伴奏／ベース／打楽器）は、オフライン録音で測ってそろえてある（`arrangements.js` の末尾 `FMIX`）。
