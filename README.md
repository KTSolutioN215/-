# ぶつかり勇者（BUMP HERO）

指でグリグリ動かして体当たりで戦う、ドット絵のダンジョンRPG。絵も音もすべてコードで生成している。

## APK
`main` に push すると GitHub Actions が APK をビルドし、Releases の **latest** に `ButsukariYusha.apk` を置く。
スマホで Releases ページを開いてダウンロード → インストール（提供元不明のアプリの許可が必要）。
署名は固定のデバッグ鍵（`app/debug.keystore`）なので、新しいビルドを上書きインストールできる。

## 構成
```
web/                 ゲーム本体（このフォルダだけでブラウザでも動く）
  index.html         画面（ページ本文。claude.ai のアーティファクトと同じ形）
  yusha.js           ゲーム本体（ダンジョン・操作・戦闘・ボス・街・ショップ）
  sprites.js         ドット絵（勇者・敵・ボス・タイル・置物・エフェクト）
  fantasy.js         音のエンジン（BGM・効果音・ジングル）
  arrangements.js    BGMのアレンジと音量バランス
app/                 Android（WebView でゲームを表示）。ビルド時に web/ を assets にコピー
tools/wrap.sh        web/_test.html を作る（PCのブラウザで試す用）
```
Android の戻るボタン：ウィンドウを閉じる → ダンジョンならポーズ → 街なら門のページへ → 門のページで押すとアプリを閉じる。
アプリを切り替えると、音楽とゲームは止まる。


## 遊び方
- 画面のどこでも指を置くとそこがスライドパッドになる（倒した方向・量で移動。指が外に出るとパッドがついてくる）
- パッドを**大きく倒すと突進**。オレンジに光っていれば体当たりが攻撃になり、当たると反動で跳ね返る。速いほどダメージが大きく、全開なら時々「かいしん」
- ゆっくり触れると敵の攻撃を受ける。弾・剣・火・衝撃波にも注意
- 敵を倒すと経験値とゴールド。レベルアップで HP・こうげき・ぼうぎょ が上がる
- 宝箱・木箱は体当たりで開く。ボス部屋の手前に「いやしの泉」（HP全回復）
- 右下ボタンで回復アイテム（足りないHPに合わせて自動で選ぶ）

## 街
1画面に1つの建物。左右にスワイプ（または ◀ ▶）で切り替え、建物をタップすると中に入る。
- **勇者の家**：つよさ・せってい・あそびかた
- **ダンジョンの門**（最初に表示）：ダンジョンを選んで出発
- **どうぐや**：やくそう・ポーション・エリクサー
- **かじや**：ぶき・よろい・くつ・そうしょく

アプリを閉じたり別のアプリに切り替えたりすると、ゲーム（音楽・処理）はすべて止まり、ダンジョン中ならポーズになる。

街に戻るとHPは全回復（宿屋は廃止）。やられると、その探索で拾ったゴールドの半分を失う（レベル・経験値はそのまま。ポーズから自分で街へ帰った場合は失わない）。セーブはブラウザに自動保存。

### 難易度の目安
- 1〜5ステージ：初見でそのまま進めばクリアできる強さ（1回のクリアで次の推奨Lvに届く経験値）
- 6ステージ以降：最新のステージを3回ほど回ってレベル上げ・お金かせぎをすると、次のステージに挑める強さ
- 1回の探索で手に入るゴールドはステージごとに約1.2〜1.45倍。3回分で次のランクの装備が買える目安
- 16ステージ以降も同じ考え方（ボットで試すと、1ステージあたり周回1〜3回＋挑戦の失敗1〜2回）。まおうは最後らしく少し手ごわい
- 15ステージ版のセーブデータはそのまま引き継げる（魔王城をクリア済みなら25番目にクリア印が付き、15番目から挑める）

### 装備・アイテム
- 装備は25ステージ分：ぶき16種（〜ひかりの聖剣）・よろい15種（〜ひかりの聖よろい）・くつ7種（〜時空のくつ）・そうしょく9種（〜ひかりの宝玉）
- **コンボ**：つづけて当てるとヒット数が増え、5ヒット目から1ヒットごとに威力+2%（最大+50%）。被弾するか、しばらく当てないと0に戻る
- **ドロップ装備**（ショップでは売っていない。ふだんの体当たりで倒した敵から）
  - さびた〜／ぼろぼろの〜：ショップ装備の下位互換（約80%）。1体あたり1.2%
  - ◆特殊効果つき：能力はショップのやや下（約85%）だが効果がある。1体あたり0.6%。15種類×2段階＝30品（各ダンジョンの近くの品だけ出る）
  - ★名工の〜：ショップ装備の上位互換（約130%）。1体あたり0.2%、ボスは5%
  - すでに持っている品はゴールドに変わる。手に入れた品はすぐ袋に入るので、やられても失わない
  - 特殊効果（同じ効果は重ならない）：かいてん（回りながら当てると+20%）、しずかな一撃（ゆっくり当てるほど会心が出やすい・最大30%）、はねかえり（反動1.5倍・敵も大きく吹き飛ぶ）、れんげき（ヒット数2倍）、きゅうけつ（倒すとHP3%回復）、しょうにん（ゴールド+15%）、まなび（経験値+10%）、くすし（アイテムのクールタイム-2秒）、やくそうし（回復量+30%）、ゆうき（HP満タンで+15%）、はいすい（HP30%以下で+25%）、れんぞく（コンボの持続+1秒）、ボスごろし（ボスに+10%）、みかわし（被弾後の無敵+0.3秒）、れんきん（くすりの効果時間+50%）
- **装備の変更**：勇者の家とポーズ画面の「そうび」から。ダンジョンの中で替えるとすぐ反映される
- どうぐ：やくそう／ポーション／ハイポーション／エリクサー（回復量は最大HPの割合）、ちからのくすり（20秒こうげき1.5倍）、まもりのくすり（20秒ダメージ半分）
- ダンジョンでは右下の「どうぐ」ボタンでトレイを開いて使うアイテムを選ぶ（選んでいる間はゲームが止まる）
- アイテムを使うと6秒のクールタイム（全アイテム共通）。ボタンが暗くなって残り秒数が出て、明るさが戻ると次が使える。クールタイム中はトレイも開かない（ゲームの一時停止を使った連続回復はできない）

## キャラクターの見た目
勇者・ザコ敵47種（うち色違い20種）・ボス25体は、すべてドット絵の2.5頭身チビキャラ（`sprites.js`）。
- 絵はコードで描いている。小さなキャンバスに四角や多角形で描き、くっきりしたドットに整え、1ドットの黒い縁取りを付けて、ポーズごとにキャッシュする。1ドット＝1.5ピクセルで、全キャラ同じ密度。
- 勇者：
  - 上下左右の4方向と歩きの動きがある。
  - 突進中は剣を突き出し、残像が出る。
  - やられたときの顔、まばたき、マントのはためきもある。
  - 武器16種・防具15種の組み合わせで見た目が変わる（剣の色・長さ・光、よろい・かぶと・盾・マントの色）。
- ザコ敵：構え・攻撃・突進・詠唱などの状態ごとにポーズが変わる。勇者のいる側を向く。
- ボス：
  - 待機と攻撃のポーズがある。HPが半分を切ると、目の色が変わり、赤いオーラが出る。
  - ヴォイドアイは勇者を目で追う。
  - キングスライムはジャンプ中に縦に伸びる。
- 当たり判定はこれまでどおり丸のまま。キャラの足元を丸の下側にそろえてある。

## 画面全体のドット化
- 街・ダンジョン・ボス部屋・攻撃エフェクトは、すべて低解像度のドット絵レイヤー（1ドット＝1.5ピクセル、キャラと同じ密度）に描いて、ぼかさずに拡大している。
- カメラと揺れはドット単位でそろえている。文字（ダメージ数字・看板・メニュー・HUD）は上の層にくっきり描く。
- ダンジョンの床は25種類のタイル：
  - 石畳、森の土と草、坑道、水晶、地下墓地、溶岩のひび、氷、大理石と金の目地
  - 砦のレンガ、ぬれた石と苔、砂岩、木の床と真鍮、星空、魔界の黒曜石、魔王城の市松模様
  - 毒の沼、船の甲板、岩山と雪、図書館のじゅうたん、苔むした神殿の石、鉄板と溶けた鉄の目地、鏡のタイル、深海の砂とサンゴ、骨の散らばる地面、ひび割れた魔界の大地
- 壁もドットのレンガ。
- 置物もドット絵：
  - 松明（炎が3コマ）、岩（大きさ別）、木箱、宝箱（開く・閉じる）、いやしの泉（水面が揺れる）、トゲ床
  - ゴールド（回転）、やくそう・ポーション
- 弾もドット絵：魔法弾、火球、大火球、追尾弾、胞子、クモの糸、岩、矢。
- 攻撃予告の範囲は網点（ディザ）表示。
- 体当たりの火花（かいしんは大きい）と、敵を倒したときの煙はドットのアニメーション。
- 街もドット絵：
  - 帯状の夕焼け空と月、山並みと魔王城のシルエット
  - 芝生と石畳の道
  - 壁の板・れんが、うろこ屋根の質感、光る窓、扉
  - 店の中：棚の薬びんや剣と盾、店主（どうぐやの娘・かじやの親方）
- 低解像度で描くぶん処理も軽くなった（手元の計測で1フレームが約8分の1）。

## 効果音
DOPAMINE TUNNEL の効果音とボイスをやめ、ファンタジー風の効果音を `fantasy.js` で合成している（28種）。
- **戦い**：体当たり（ドスッ）、かいしん（斬撃とキラキラ）、ボスへの一撃、盾ではじかれる（カキン）、被弾、敵をたおす（ボフッとキラキラ）、地響き、爆発、魔法弾、怪しい弾、召喚、ワープ、ボスの咆哮
- **探索**：コイン（連続で拾うと音程が上がる）、宝箱（きしみとジャーン）、木箱をこわす、アイテムを拾う、回復（ハープ）、いやしの泉、ちからのくすり・まもりのくすり、レベルアップのファンファーレ、ボス部屋の扉、ボス登場（どら＋金管）、やられた
- **街**：決定・選択（ハープ）、出発、買い物（コインとベル）、装備（剣を抜く音）
- BGMと効果音は同じ出力（音量設定・圧縮）を通る。効果音は小さな部屋の響きをまとっている。

## 音楽
DOPAMINE TUNNEL のダンス曲エンジンをやめ、王道ファンタジーのオーケストラ風BGMを新しく作った（`fantasy.js`。サンプル音源は使わず、すべてWeb Audioで合成）。

- **3つのテーマ曲**（オリジナル）
  - 冒険のマーチ：ダンジョンの曲（勇ましい4拍子、前奏＋A・A'・Bの32小節）
  - たたかいのテーマ：ボス戦の曲（疾走する短調、前奏＋A・B・A・Cの28小節）
  - 村のワルツ：街の曲（のどかな3拍子、32小節）
- メロディは「音階の何番目か」で書いてあるので、同じ曲を長調・短調・フリギア（スペイン風）・二重和声的音階（中東風）などに置きかえられる。
- **アレンジ**（`arrangements.js`）：調・旋法・テンポ・楽器・伴奏・ベース・打楽器・残響・環境音をダンジョンごと、ボスごとに変えている。例：
  - まよいの森：自然的短音階、フルートのこだま、フクロウ
  - 溶岩洞：フラメンコ風（ギター、カスタネット、手拍子）
  - こおりの塔：オルゴールと鈴
  - ピラミッド：ウードとダルブッカ
  - 時計塔：チェンバロとチクタク
  - 魔王城：パイプオルガンと合唱
- ボスはHPが半分を切ると、テンポが上がり、トレモロと金管が加わる（まおうは半音上に転調）。
- 街は建物を切り替えると、次の小節から楽器が変わる。門はフルートと弦、勇者の家はオルゴール、どうぐやはクラリネットとピチカート、かじやはホルンと金床。
- ダンジョン制覇のファンファーレと、やられたときの短い曲もある。
- 勇者の家の「おんがくしつ」で、たどりついたダンジョンとたおしたボスの曲（いかり版も）をきける。
- 楽器ごとの音量と各曲のパートバランス（メロディ／伴奏／ベース／打楽器）は、オフライン録音で測ってそろえてある（`arrangements.js` の末尾 `FMIX`）。
